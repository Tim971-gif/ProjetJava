# Schotten-Totten (projet PROG1)

Jeu Schotten-Totten en Java, en mode console.

## Organisation

- `src/com/schottenTotten/model` : classes du jeu (Carte, Borne, ...)
- `src/com/schottenTotten/controller` : logique du jeu, éditions, JeuFactory
- `src/com/schottenTotten/view` : affichage console
- `src/com/schottenTotten/ai` : intelligences artificielles
- `test` : tests JUnit
- `rapport` : rapport de conception
